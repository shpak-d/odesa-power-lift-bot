# Дослідження джерел — 23.11.2026

Оператор обох ліній підтверджений користувачем: ДТЕК Одеські електромережі.

## Відповідність оператора

Надані сторінки [2.1](https://alerts.energy/odeska-oblast/schedule/odeska-oblast-uz/2.1)
і [4.1](https://alerts.energy/odeska-oblast/schedule/odeska-oblast-uz/4.1) у заголовках
визначають оператора як АТ «Укрзалізниця». Для ДТЕК slug сторінки —
`odeska-oblast-oblenergo`, ідентифікатор API — `odeska_oblast_oblenergo`.
Номери черг самі по собі не ідентифікують оператора.

## Обраний спосіб

Звичайний GET [сторінки ДТЕК](https://www.dtek-oem.com.ua/ua/shutdowns) під час
перевірки повернув HTTP 200 без авторизації. У HTML виявлено:

- `DisconSchedule.fact`: `data`, `today`, `update`.
- `data`: Unix timestamp місцевої півночі → `GPV2.1` / `GPV4.1` → години `1`…`24`.
- `update`: місцевий час `DD.MM.YYYY HH:MM`.
- `preset.time_zone`: наприклад, `1: ["00-01", "00:00", "01:00"]`.

Семантику перевірено за `preset.time_type` та
[публічним JavaScript ДТЕК](https://www.dtek-oem.com.ua/src/js/static/discon-schedule.js):

| Значення | Інтервал відключення |
|---|---|
| `yes` | немає планового відключення |
| `no` | вся година |
| `first` / `second` | перші / другі 30 хвилин |
| `maybe` | можливе відключення протягом години |
| `mfirst` / `msecond` | можливе відключення перших / других 30 хвилин |

`preset.data` — тижневий шаблон, не використовується як актуальний датований графік.
Парсер перевіряє оператора, сітку, дату сторінки та повноту 24 годин. JSON декодується
без виконання JavaScript. Захисні ресурси Incapsula не викликаються.

## Документований альтернативний API

[Документація графіків операторів](https://alerts.energy/developers/api/operators/source-registry-areas-slug-shutdowns)
описує GET `/api/v1/source-registry/areas/:slug/shutdowns`, Bearer-авторизацію,
датовані поля `today_date/tomorrow_date`, стани публікації та 24 годинні коди
`0/1/2/3`. [Підключення](https://alerts.energy/developers/api) потребує активної
підписки. Адаптер реалізований за цією схемою, але перевірка із платним ключем
не виконувалася: ключ не наданий. Внутрішні маршрути та платний доступ не обходимо.

Це результати одноразової перевірки, не гарантія майбутньої доступності джерел.
